## Registry Entries

A registry entry describes one named config contribution.

```ts
type VariantDefinition<T> = {
  extends?: string | string[];
  active?: boolean;
  config: Partial<T>;
};
```

An entry can be a small feature such as `breadcrumbs`, `hero`, `toc`, or
`sidebar`. It can also be a layout variant such as `article`, `landing`, or
`event`.

## Feature Composition

Variants compose features through `extends`.

```ts
registry: {
  breadcrumbs: {
    config: { breadcrumbShowHome: true },
  },
  hero: {
    config: { heroHeight: "md" },
  },
  article: {
    extends: ["breadcrumbs", "hero"],
    config: { heroHeight: "sm" },
  },
}
```

`article` inherits `breadcrumbShowHome` and `heroHeight`, then overrides
`heroHeight`.

## Shorthand Extends

When a variant only extends other entries and has no own config, use an array.

```ts
registry: {
  event: ["breadcrumbs", "hero"],
}
```

This is equivalent to:

```ts
registry: {
  event: {
    extends: ["breadcrumbs", "hero"],
    config: {},
  },
}
```

## Merge Priority

When `useVariant("article")` resolves config, the final value priority is:

1. `app.config` for `article`
2. `nuxt.config` for `article`
3. last parent in `extends`
4. earlier parents in `extends`

Objects are deeply merged. Arrays are replaced, not concatenated.

## Inactive Variants

Set `active: false` when a registry entry should exist in the graph but not
contribute behavior.

```ts
registry: {
  draft: {
    active: false,
    extends: ["hero"],
    config: { heroHeight: "sm" },
  },
}
```

`useVariant("draft").config` resolves to an empty object, and
`useVariant("draft").has("hero")` is `false`.

## Diagnostics

Nuxt Variants reports graph issues during Nuxt prepare:

- unknown parent variants
- circular inheritance chains
- `app.config` overrides that replace a base `extends` chain

Diagnostics are also available as `variantDiagnostics` from `#variants-graph`
and in the Nuxt DevTools inspector.

## DevTools Inspector

During development, Nuxt Variants adds a `Nuxt Variants` tab to Nuxt DevTools.
Use it to inspect:

- every registered variant
- direct `extends` relationships
- active inherited features
- base registry config and `app.config` overrides
- resolved config after inheritance and merge priority
- diagnostics for graph issues

The inspector is development-only and does not register its server route in
production builds.
