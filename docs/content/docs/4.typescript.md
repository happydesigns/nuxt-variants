Nuxt Variants generates a `CustomVariantRegistry` from your registry and
app config. Literal values are widened to primitive types so the generated
types stay ergonomic.

## Generated Config Types

After `nuxt prepare` or `nuxt dev`, a literal variant name gives a typed config.

```ts
const { config } = useVariant("article");

config.value.heroHeight;
config.value.breadcrumbShowHome;
config.value.authorBox;
```

Inherited fields are included in the resolved type.

## `VariantConfigOf`

```ts
import type { VariantConfigOf } from "#nuxt-variants";

type ArticleConfig = VariantConfigOf<"article">;
```

## Manual Augmentation

Use manual augmentation when you need narrower literal unions.

```ts [types/variants.d.ts]
declare module "#nuxt-variants" {
  interface CustomVariantRegistry {
    hero: {
      heroHeight: "sm" | "md" | "lg" | "xl";
      heroOverlay: boolean;
      heroAlign: "left" | "center" | "right";
    };
  }
}
```
