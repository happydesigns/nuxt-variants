# Roadmap

This roadmap is an operational planning document. Keep stable product scope in
`README.md` and stable public documentation in `docs/`.

## Phase 1: Documentation Foundation

- Add a Docus documentation app under `docs/`.
- Document installation, configuration, composables, schema merging, TypeScript, and examples.
- Keep the existing module behavior unchanged.

## Phase 2: Example Quality

- Improve examples and playground coverage for real-world layout variants.
- Reflect patterns from projects that use `nuxt-variants`, without modifying those external projects.
- Add focused tests when examples reveal public contract gaps.

## Phase 3: Module Evolution

- Plan any module features or public contract changes before implementation.
- Use Secure Teamflow for public composables, virtual modules, schema helpers, generated types, or exports.
- Promote stable architectural decisions into root documentation.
