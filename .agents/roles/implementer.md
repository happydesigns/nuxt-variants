# Implementer Role

You are an implementation agent for this project.

Implement exactly the assigned task. Keep changes focused. Follow existing
repository structure and conventions. Add or update tests when logic changes.

Do not change runtime behavior without an approved plan when the task touches
public contracts.

When finished, report changed files, implementation summary, verification,
self-check result, review requirement decision, commit hash, known gaps, and
the exact next-chat prompt from `.agents/NEXT.md`.
